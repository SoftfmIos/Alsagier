# Arabic localization — Stage 1

Added Arabic string catalog with 170 interface entries, registered it as an XcodeGen resource, and retained app-wide Arabic locale / RTL setting. User-created names and data are unchanged.

Source is Version 6.0 Build 23 (Build 22 already uploaded). No iOS SDK compilation has been performed.
